# 报告契约

> 权威范围：Prometheus 与脱敏归因 JSON/Markdown 输出

每份报告必须包含报告日期和时区、生成时间、程序与规则版本、节点状态、命中规则、阈值快照、Prometheus 查询窗口、target/label 身份、样本覆盖率、普通与 AI 数据面的日流量总量、可用时的脱敏 user/inbound 流量归因、缺失与冲突序列、报告模式和 SQLite 审计运行 ID。

证据引用只允许使用指标名、受控标签、时间范围、脱敏引用和聚合值。不得嵌入原始日志、请求内容、客户端标识、凭据、原始用户 email/UUID、inbound tag、访问域名、URL 或全量 Prometheus 样本。

Markdown 固定展示摘要、节点状态、指标覆盖、入站/出站/合计流量、脱敏归因、规则事件、数据缺口、能力边界和人工处置建议。JSON 是机器可读权威结果，Markdown 必须由同一 JSON 固定渲染。两种格式应原子发布并记录内容摘要，默认保留 90 天。

`normal` 表示已配置指标在覆盖充分时未命中异常规则，不表示不存在指标之外的问题；`unknown` 表示证据不足，不得解释为正常。
