# 文档首页

## 建议阅读顺序

1. [architecture.md](architecture.md)：先理解控制面、数据面和 AI 路由的边界。
2. [development.md](development.md)：本地启动、调试和常用命令。
3. [configuration.md](configuration.md)：根 `.env` 与 `app/xray/.env` 的配置方式。
4. [api.md](api.md) / [operations.md](operations.md)：接口细节、健康检查、探针、统计链路。
5. [ai-routing.md](ai-routing.md) / [kubernetes.md](kubernetes.md)：按需阅读 AI 路由和 K3s 部署。
